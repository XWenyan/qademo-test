# QADemo JMeter Performance Test

## 1. 测试目的

使用Apache JMeter对QADemo电商系统商品列表接口进行性能测试，观察不同负载模型下接口的响应时间、吞吐量和稳定性。

测试接口：

`GET /api/products`

## 2. 测试环境

* JMeter：5.6.3
* Server：127.0.0.1:8787
* Test Tool：Apache JMeter
* Test Type：API Performance Test

## 3. 测试场景

每个线程循环请求商品列表接口 10 次，分别采用稳定加压和快速加压两种负载模型。

| 场景   | Threads | Ramp-up | Loop Count |
| ---- | ------: | ------: | ---------: |
| 稳定负载 |     100 |    100s |         10 |
| 快速加压 |     100 |     10s |         10 |

## 4. 测试结果

| 场景   | Average |    P95 |    P99 |    Max | Error | Throughput |
| ---- | ------: | -----: | -----: | -----: | ----: | ---------: |
| 稳定负载 |    19ms |   26ms |   36ms |   65ms |    0% | 10.1 req/s |
| 快速加压 |   915ms | 1091ms | 7488ms | 8806ms |    0% | 46.8 req/s |

## 5. 测试结论

在稳定加压场景下，接口平均响应时间约 19ms，P95 为 26ms，未出现请求失败。

在快速加压场景下，接口平均响应时间上升至 915ms，P95 达到 1091ms，P99 达到 7488ms，出现明显的长尾延迟，但请求错误率仍为 0%。

结果表明，在当前本地测试环境和负载模型下，QADemo 商品列表接口在快速增加并发负载时出现明显的响应性能退化。
